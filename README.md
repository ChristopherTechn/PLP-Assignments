# Discount Calculator

This Python program calculates the final price of an item after applying a discount, based on the original price and discount percentage provided by the user. If the discount is 20% or higher, it applies the discount; otherwise, the original price is returned.

## Features
- Accepts user input for price and discount percentage
- Applies the discount if 20% or higher
- Displays the final price after discount (or original price if no discount applied)
