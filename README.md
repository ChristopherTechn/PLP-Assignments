# 🧮 Basic Python Calculator

A simple command-line calculator built with Python.  
It allows the user to input two numbers and perform one of the four basic mathematical operations: addition, subtraction, multiplication, or division.

---

## 🚀 Features

- Accepts user input for two numbers
- Supports the following operations:  
  ➕ Addition  
  ➖ Subtraction  
  ✖️ Multiplication  
  ➗ Division (with division-by-zero handling)
- Prints the result in a readable format

---

## 🛠 Requirements

- Python 3.x
- VS Code or any Python-compatible IDE/text editor

---

1. Clone or download the project.
2. Open the folder in [Visual Studio Code](https://code.visualstudio.com/).
